# Aux Douces Mains — maquette de démonstration (non officielle)

Maquette de site pour l'institut de beauté **Aux Douces Mains** (La Brillanne, 04), réalisée à partir de ses pages publiques Facebook et Google. **Ce n'est pas le site officiel de l'institut** : les informations sont à confirmer avec l'établissement avant toute utilisation.

- Photos, avis et horaires : pages publiques Facebook et Google de l'institut (avis Google, noms abrégés).
- Vidéo d'accueil : plans libres de droits Mixkit + photographie de l'institut.
- Site statique (HTML, CSS, JavaScript), non indexé par les moteurs de recherche.
